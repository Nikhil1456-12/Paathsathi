PathSaathi Offline AI Models
============================
Models are downloaded to the app documents directory at first launch.

Minimum required:
  - Whisper tiny INT8 (31MB)  -- offline Hindi/Telugu/Tamil STT
  
Optional (enhance AI routing quality):
  - MobileBERT NLU INT8 (25MB) -- on-device intent classification
  - Gemma 1B INT4 (652MB)      -- on-device LLM agent routing
  - MBTiles Prayagraj (180MB)  -- real offline map tiles

All models run 100% on-device. No internet required after download.
